# wireframe-md

Low-fidelity wireframes in Markdown.

Current scope is intentionally narrow:

- fenced `wireframe` blocks
- screens only
- HTML rendering
- golden visual tests from Markdown fixtures

Example:

````md
```wireframe[980x680]
screen dashboard title="Dashboard" device=browser
```
````

Packages:

- `@wireframe-md/core`: parser and screen model
- `@wireframe-md/html`: HTML renderer and default CSS
- `@wireframe-md/remark`: remark plugin for fenced blocks

Development:

```sh
npm install
npm run build:site
npm run test
npm run test:visual:update:docker
npm run test:visual:docker
```

Visual fixtures live in [`tests/visual/fixtures`](/Users/ben/Projects/Uberblick/wireframe-md/tests/visual/fixtures). Golden screenshots are generated by Playwright and should be committed with fixture changes.

The GitHub Pages showcase is built from [`site/catalog.js`](/Users/ben/Projects/Uberblick/wireframe-md/site/catalog.js) into `site-dist/` via `npm run build:site`.
